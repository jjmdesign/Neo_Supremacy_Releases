# NEO SUPREMACY

Public beta builds of NEO SUPREMACY.

## Current Beta

Version: 0.1.0-beta.1

### Installation

1. Download the latest Windows ZIP from Releases.
2. Extract the ZIP.
3. Run `NeoSupremacy.exe`.
4. Choose Host Game or Join Game.

### Beta Notice

NEO SUPREMACY is currently in private/public beta testing.
Save compatibility and gameplay may change between beta versions.
